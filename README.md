# Heiß OS (`heiss`)

> Красивый, удобный и безопасный Linux-дистрибутив на базе Arch Linux. Для обычных людей и для специалистов по кибербезопасности.

**Статус:** ранняя концепция. Загрузочного образа пока нет.

*Heiß OS (произносится «Хайсс», ASCII-вариант: Heiss) — независимый проект. Основан на Arch Linux, но не является официальным продуктом Arch Linux и не связан с ним.*

---

## Идея

Система при первом запуске спрашивает, для чего вам нужен компьютер, и подстраивается под сценарий.

| Профиль | Для чего |
|---|---|
| **Everyday** | Учёба, интернет, мультимедиа и повседневная работа |
| **Security** | Пентестинг, анализ сетей, форензика и лаборатории |
| **Developer** | Программирование, Git, компиляторы и контейнеры |
| **Universal** | Сбалансированный набор для разных задач |

Профили будут реализованы как метапакеты поверх одного образа. Их можно будет менять и сочетать после установки.

## Ключевые решения

- **База:** Arch Linux (используем его пакеты и экосистему, собственное ядро не разрабатываем).
- **Рабочий стол:** KDE Plasma (в первой версии единственный).
- **Установщик:** графический, на основе Calamares. Читать гайды по Arch не нужно.
- **Телеметрия:** отсутствует.

## Собственные инструменты

- **Heiß Security Center:** проверка обновлений, брандмауэра, конфигурации и защитных механизмов, понятные рекомендации и кнопка «Исправить».
- **Heiß Security Labs:** изолированные лаборатории для изучения сетей, анализа трафика и безопасного тестирования своих систем (в перспективе).

## Дорожная карта

1. **MVP:** загрузочный ISO с KDE, брендингом и Calamares, профиль Everyday.
2. **v0.2:** Btrfs-снапшоты, собственный репозиторий пакетов, Welcome-приложение.
3. **v0.3:** остальные профили.
4. **v0.4:** Security Center v0.1.
5. **Далее:** Security Labs.

Текущие задачи: вкладка **Issues** и доска **Projects** организации.

## English summary

**Heiß OS** is an early-stage, Arch-based Linux distribution with KDE Plasma, a graphical installer (Calamares) and profile-based setup (Everyday, Security, Developer, Universal). It will ship its own security tooling: *Security Center* (system hardening checks with plain-language fixes) and *Security Labs* (isolated labs for learning and testing). No telemetry. Heiß OS is an independent project and is not affiliated with Arch Linux.
