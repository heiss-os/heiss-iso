Шрифты Heiss OS — Inter 4.1 (лицензия SIL Open Font License 1.1, см. LICENSE.txt)

Акцентный шрифт (заголовки экранов, важные моменты):
  static/Inter-ExtraBoldItalic.ttf
  static/InterDisplay-ExtraBoldItalic.ttf   — для крупных заголовков (от 28 px)

Основной шрифт (весь остальной текст):
  static/Inter-Regular.ttf    — обычный текст, пояснения, поля ввода
  static/Inter-Medium.ttf     — подписи полей, сообщения об ошибках
  static/Inter-SemiBold.ttf   — кнопки

Вариативные версии (альтернатива статическим файлам, все жирности в одном файле):
  variable/InterVariable.ttf          — прямой: 400 Regular, 500 Medium, 600 SemiBold
  variable/InterVariable-Italic.ttf   — курсив: 800 ExtraBold Italic

Файл LICENSE.txt обязательно распространяйте вместе со шрифтами.
